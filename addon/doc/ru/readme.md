## Представление

Clipspeak - это дополнение, которое позволяет NVDA автоматически объявлять об операциях с буфером обмена (таких как вырезание, копирование и вставка), а также о других распространенных операциях редактирования, таких как отмена и повтор.
Чтобы предотвратить объявления в неподходящих ситуациях, Clipspeak выполняет проверку системы управления и буфера обмена, чтобы принять обоснованное решение о необходимости такого объявления.
Вы можете выбрать между объявлением только о копировании / вырезании / вставке или о том, что копируется / вырезается / вставляется в NVDA, configurations, clipspeak.
По умолчанию жесты Clipspeak сопоставляются с теми, которые обычно используются в англоязычных версиях Windows:

* CTRL+Z: Отменить
* CTRL+Y: Повторить
* CTRL+X: Вырезать
* CTRL+C: Копировать
* CTRL+SHIFT+C: Копировать путь к файлу (только в Windows 11)
* CTRL+V: Вставить

Если это не те сочетания клавиш, которые обычно используются для этих задач в вашей версии Windows, вам нужно будет переназначить эти жесты в конфигурации жестов ввода в категории Буфер обмена.
